# Manual funcional de PideAca

Guía ilustrada del funcionamiento del sistema, de punta a punta.
Idioma: español. Fuentes versionadas junto al código.

## Índice

1. `01-mapa-general.md` — Mapa del sistema: módulos, roles y flujos principales.
2. `web/10-consultas-sugerencias.md` — Ventana web: Consultas y sugerencias (+ estadísticas por país).
3. `flujos/20-registro-activacion.md` — Flujo transversal: registro y activación de cuenta.
4. `movil/30-consultas.md` — Pantalla móvil: Consultas.

> Cada capítulo incluye captura real generada por el robot QA (`qa/`).
> Para regenerar el PDF: `node docs/manual/build-pdf.js` (requiere Chrome).
